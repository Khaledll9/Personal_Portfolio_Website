## 📖 About The Project

This is my personal portfolio — a visual and interactive resume designed to communicate who I am, what I do, and what I've built. Whether you're a potential client, collaborator, or employer, this site gives you a clear snapshot of my skills, services, and past work.

**The problem it solves:** A developer without a portfolio is invisible. This site puts my work front and center in a polished, professional format that loads instantly — no frameworks, no bloat.

**Target audience:** Recruiters, freelance clients, open-source collaborators, and anyone curious about my work.

---

## ✨ Key Features

- **🧭 Smooth Navigation** — Fixed sticky header with anchor links to every section
- **📱 Fully Responsive** — Adapts seamlessly from desktop down to mobile (breakpoint at 1040px)
- **🎬 Animated Hero** — Typewriter-like cycling text (Flutter, Web, Design roles)
- **📊 Skill Bars** — Animated progress bars for Flutter, UI/UX, Web, and Graphic Design
- **🃏 Service Cards** — Hover-animated cards explaining what I offer
- **🖼️ Project Gallery** — Screenshots of mobile apps with hover zoom effect
- **📬 Contact Section** — Contact cards (address, phone, email) and a message form
- **🔝 Scroll-to-Top** — Floating button appears after scrolling down
- **👁️ Scroll Reveal** — Elements fade in as they enter the viewport
- **🍔 Mobile Menu** — Hamburger toggle with full-screen sidebar navigation

## 🏗️ Architecture & Tech Stack

| Layer | Technology |
|-------|-----------|
| **Markup** | HTML5 (semantic sections) |
| **Styling** | CSS3 (Flexbox, custom properties, keyframe animations, media queries) |
| **Logic** | Vanilla JavaScript (ES6) |
| **Icons** | Font Awesome 5.15.2 |
| **Fonts** | Google Fonts — Poppins |
| **Hosting** | GitHub Pages (static site) |

**Pattern:** Single-page application (SPA-like) with vanilla JS — no frameworks, no build step. Each section is an `<section>` element with an `id` matching the nav anchor. Scroll interactions (sticky header, reveal animations, scroll-to-top visibility) are handled by a single `scroll` event listener.

```
📦 khaled-mamdooh-website
├── 📄 index.html       ← Main entry point (all sections)
├── 📄 style.css        ← All styles (~700 lines, responsive)
├── 📄 script.js        ← Vanilla JS (~50 lines)
├── 📄 AGENTS.md        ← OpenCode instruction file
├── 📄 README.md        ← You are here
└── 📁 images/
    ├── bg.jpg          ← Hero background
    ├── my_photo.jpg    ← Personal photo
    ├── app1.png        ← App screenshot
    ├── app2.png        ← App screenshot
    ├── app3.png        ← App screenshot
    ├── menu.png        ← Hamburger icon
    └── close.png       ← Close icon
```

## 🚀 Getting Started

### Prerequisites

Nothing. This is a static website — zero dependencies.

> ✅ Any modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Khaledll9/khaled-mamdooh-website.git

# 2. Navigate into the project
cd khaled-mamdooh-website

# 3. Open in your browser
start index.html          # Windows
open index.html           # macOS
xdg-open index.html       # Linux
```

That's it. No `npm install`, no build command, no dev server. Just double-click `index.html` or run the command above.
